# Forum Chem's Magazine

Cette petite application web fournit un forum hors ligne pour le magazine **Chem's Magazine**.
Elle fonctionne uniquement dans le navigateur grâce au `localStorage`.

## Fonctionnalités

- Connexion avec choix du rôle *Utilisateur* ou *Administrateur*
- Création de sujets avec un titre et un contenu
- Liste des sujets publiés
- Section administration visible uniquement pour les administrateurs avec possibilité de supprimer des sujets
- Sauvegarde des données (utilisateur et sujets) dans le `localStorage`

Ouvrez simplement `index.html` dans un navigateur moderne pour utiliser le forum.
